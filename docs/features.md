# 功能清单

按界面导航顺序列出，标注实际能力与限制。**标注「仅存档」的参数不会进入请求**——这点在界面上
也是明确写出的，不做「看起来生效」的假象。

## 项目总览

- 多项目并存，卡片显示集数、画幅、镜头数、完成度、更新时间
- 项目改名（卡片与顶栏两个入口）
- 新建项目 / 从 JSON 导入项目
- 当前项目的完成度、情节点、资产、分镜、生成任务统计
- 最近运行日志（只记任务状态，不记 API Key）

## 剧本拆解

- 剧本编辑与保存
- AI 续写 / 改写（走当前配置的对话模型）
- 本地拆分情节节拍（不依赖模型，可离线跑）
- 剧本版本回滚

## 角色与资产

- 三类资产：角色 / 场景 / 道具
- 角色定妆图上传或生成、三视图生成、变体管理
- 提示词编辑、手动修改留档（改前版本归档，可追溯）
- 资产提示词 AI 生成

## 创作控制

- 镜头级参数：景别、运镜、风格、音轨等
- 参数按**资产类型与模型能力**动态渲染，不出现无意义字段（例如图片模型不会出现音轨）

## 分镜导演

- 由情节点一键生成分镜
- 手动增删镜头、镜头入队
- 生成失败的镜头可筛选、单条重试
- 逐镜状态：待生成 / 排队 / 生成中 / 已完成 / 失败

## 生成执行

- 任务队列与并发控制
- 免费额度保护开关（可限制单次调用规模）
- 任务日志与失败原因

## 交付中心

- 字幕：由分镜台词生成 SRT，支持字体与位置样式
- 分镜表 CSV 导出
- 提示词包导出
- EDL 剪辑决策表导出
- 封面渲染（取首帧压暗 + 标题排版）
- 剪映草稿生成（明文工程结构，可直接进剪映）
- 成片合成：ffmpeg filter graph（归一化 / 变速 / 转场 / 调色 / 烧字幕 / 混音）

## 模型与设置

- 四级层级树：模块 → 服务商 → 模型 → 参数
- 每个服务商的 API Base、Endpoint、凭据状态
- 每个模型的参数表单（枚举下拉、数值范围、布尔开关），越界值保存时拦截
- 通道切换：只改「当前用哪家」，不动其他服务商的配置
- 哪些参数真正进请求、哪些仅存档，逐项标注
- Key 只在本机保存，界面不回显明文

## 已实现但有限制的部分（如实标注）

| 项 | 状态 |
|---|---|
| OpenAI Sora / MiniMax 海螺的视频通道 | 标「待接入」，按钮禁用——提交与轮询未接本地代理 |
| 服务商连通性测试按钮 | 未做。`file://` 下的探测会给出假成功，宁可不做 |
| 适配器真实联调 | 需要各自 API Key，未逐一实测 |

## 工具

- 项目搬迁：从旧安装导入项目、配置与**被引用的**媒体文件（不整体拷贝媒体目录），写入前自动备份
- 出处校验：文件清单生成与签名、启动自检
- 界面探针：41 项断言，真浏览器点击
